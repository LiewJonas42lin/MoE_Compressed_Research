# MoE Compressed Research [MoE LLM 的专家混合位宽压缩方案探索]

Research on mixed-precision quantization for
Mixture-of-Experts (MoE) language models.

## Research Objectives

- Study MoE architecture and expert routing.
- Investigate expert-wise quantization sensitivity.
- Explore mixed-precision bit-width allocation.
- Evaluate model quality, memory usage, and inference performance.
