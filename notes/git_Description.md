# Git Basics

## Repository

A repository stores project files and their Git history.

## Commit

A commit records a snapshot of the project at a specific point in time.

## Branch

A branch provides an independent line of development within a repository.

## Fork

A fork is a copy of another repository under a different account or namespace, retaining its relationship to the original project.

## Pull Request

A pull request proposes changes for review before merging them into a target branch.
