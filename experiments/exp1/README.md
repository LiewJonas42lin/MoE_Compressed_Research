## OLMoE 7B
后续主要用此模型开展研究。16 层 × 64 专家

用了自定的六类文件进行测试校准:
- general(英文)
- code
- math
- chinese
- medical
- Long-text [仍需进一步实验]
30 条 prompt(~500 tokens)

### 路由与频率
 code与自然语言类型的差距最大，与general的平均逐层 JS 为 **0.252509**，两组路由有明显差异

从同一内容来源中截取不同段落(例如同一本长篇小说的不同章节)的路由差异较之独立的内容来源，路由差异更小。来源相近内容来源相近JS明显减少

内容类型、语言、长度三个维度，但是只体现了code的差异。

模型的专家并不按照人类语言的语义划分。
